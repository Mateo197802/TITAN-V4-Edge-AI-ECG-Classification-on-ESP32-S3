# Claim Boundaries

This repository reports external validation evidence for the promoted TITAN V4 artifacts.

The arrhythmia result is full-support reportable Primary-9 external validation. The pathology result is reported for the configured Primary-5 pathology set. Cascade/OOD is a safety annex. ESP32 recordings are engineering evidence for edge acquisition and serialization.

External validation records are not used for model training or threshold tuning.
