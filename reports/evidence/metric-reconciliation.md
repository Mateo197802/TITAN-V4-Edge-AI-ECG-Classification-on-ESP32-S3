## Interpretation

The expanded read-only search recovered two further saved CEDIA Primary-9 prediction manifests. Applying their fixed class predictions gives 375/672 and 399/672 against the prior labels and 338/672 and 346/672 against rebuilt labels. These are separate runs. The 2026-05-26 CEDIA Gold report's confusion matrix recalculates to 605/672; its update table records 129 final labels equal to the CEDIA model Top-1. The current repository inference with the CEDIA Gold checkpoint hash yields 568/672 and matches 110/129 of those Top-1 values. See the [Gold evidence bundle](../../outputs/reviewer_verification/arrhythmia_primary9/cedia_gold_2026-05-26/) and the [dated search inventory](historical-metric-search-2026-09-28.json).

A follow-up source check matched the 672 `rhythm_label_name` values in CEDIA's pre-update `DATASETS_CURADOS/RHYTHM_PRIMARY_V2/manifest_external_test.csv` (SHA-256 `8190ec19f4887d4618213cbf95b9da3b68948dddba4f0233d975eba5938e5b8c`) to the sanitized original-label history. The CEDIA report gives 476/672 on that original reference and 605/672 on the final updated reference; only the latter has a saved confusion matrix. Scoring the same available checkpoint predictions yields 466/672 on original labels and 568/672 on final labels. The historical 90.03% / 87.82% is therefore not the original-reference score or an exact historical inference rerun. The full cross-check, row-level artifacts, and commands are in the [paired-reference report](primary9-paired-reference-recomputation-2026-10-03.md) and [historical report reproduction record](primary9-historical-report-reproduction-2026-10-03.md).

The 89.84% CEDIA accuracy and 90.30% weighted-F1 substantiate the user's recollection of high internal validation figures, but they describe a different checkpoint and 58,855 windows. The repository training summary also records an 89.48% best validation macro-F1 on 706 windows, but lacks prediction-level evidence. Neither figure is a score on the frozen 672-record cohort.

The 466/672 result used rebuilt single-label targets and the documented deterministic inference path. Applying current checkpoint predictions to the CEDIA final label table gives 568/672 (84.52% accuracy), not 605/672. The source confusion matrix makes the historical aggregate arithmetically verifiable, but the packaged fresh inference does not regenerate the CEDIA prediction output. The 129 CEDIA target changes and the report's missing checkpoint hash remain part of the metric provenance.

A separate CEDIA run on the same 672 IDs initially appeared useful for resolving the discrepancy. Forensic comparison found that the evaluator automatically applied 50 AI-generated target changes: every review value equals the model prediction, and every note states that it was generated automatically by AI. The CEDIA manifest's canonical labels still agree with the rebuilt source table, but the saved prediction manifest used the changed targets. Its fixed predictions produce 421/672 against the old labels and 381/672 against rebuilt labels. The report does not identify its exact checkpoint. This run therefore neither reproduces nor validates 605/672 and must not be cited as a clean external test.

CEDIA's saved pathology-supervised checkpoint has now been evaluated separately. Its training summary records pathology loss weight 0.2 and 1,811 pathology-labeled windows. The PTB-XL v1.0.3 SCP labels reconstructed all 2,580 sidecar vectors exactly. The resulting 71.58% / 41.37% metrics are materially below the historical 90.26% / 66.87% aggregate. Fixed threshold 0.65 increases mean per-label accuracy to 79.90% while macro-F1 remains 42.03%; this is a sensitivity check, not a recovered historical threshold. The legacy JSON's `configured_macro_f1_reference: 0.65` does not show which threshold was applied to historical predictions. The old checkpoint/cohort/threshold lineage is still missing, so this is not proof that the historical result is false and is not a reproduction. The saved scores allow exact metric recomputation; full inference still requires the CEDIA checkpoint/source tree, which is not redistributed.

PhysioNet Challenge 2021 describes recordings with one or more labels and supplies its own weighted Challenge metric. TITAN's 672-record report collapses each header's diagnoses to one class and computes ordinary accuracy/F1. Therefore, its values are project-specific diagnostics, not official Challenge scores. The cohort resolves to the Challenge's public `training/` partition, and checkpoint overlap is unknown. See the [official Challenge release](https://physionet.org/content/challenge-2021/1.0.3/) and [official evaluation code](https://github.com/physionetchallenges/evaluation-2021).

The CEDIA Gold Primary-5 summary reports 90.256% mean per-label accuracy and 66.874% macro-F1. Its promotion manifest declares a checkpoint SHA, but the checkpoint, linked source run summary, row-level targets/predictions, cohort count, and applied thresholds were absent at their declared locations in the 2026-10-03 check. The separately evaluated pathology-supervised CEDIA checkpoint is a distinct experiment. Source hashes and the declared checkpoint identifier are in the [Primary-5 source record](pathology-primary5-gold-source.json).

## Publication Boundary

Report the window-level results, 672-record diagnostic, historical source aggregates, and fresh CEDIA pathology measurement separately, with their sample units and evidence sources. For Primary-9, identify the reported confusion-matrix aggregate separately from the fresh model inference and disclose the 129 Top-1-matched target updates. For Primary-5, identify the values as source-reported and do not attribute the separate PTB-XL measurement to them.
