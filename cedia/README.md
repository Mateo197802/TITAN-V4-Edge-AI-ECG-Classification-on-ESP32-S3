# CEDIA Utilities

This directory keeps only minimal operational utilities:

| File | Role |
|---|---|
| `sync_data.py` | Incremental data synchronization. |
| `launch_training.py` | Training job launcher. |
| `run_job.py` | Generic remote job runner. |
| `tail_log.py` | Remote log tailing utility. |

Cluster-specific credentials and account details are not stored in this repository.
